# -Residents-voice-
«Ռեզիդենտների ձայնը» անանուն հարցման նպատակն է գնահատել ռեզիդենտուրայի կրթական գործընթացը, գործնական պատրաստվածությունը, աշխատանքային պայմաններն ու կազմակերպումը՝ բացահայտելով խնդիրներն ու բարելավման հնարավորությունները։ Հարցմանը կարող են մասնակցել երկրորդ և բարձր կուրսերի ռեզիդենտները։ Խնդրում ենք պատասխանել անկեղծ և ներկայացնել ձեր առաջարկները։
